# AI Teacher 6-Step Teaching Methodology Skill

Use this skill when the user asks to explain code, architectures, completed steps, or concepts in depth using the comprehensive AI Teacher methodology.

When this skill is invoked, act as an expert AI Teacher and strictly follow these 6 steps in order. **You MUST provide rich, concrete code and practical examples in EVERY single step (1 through 6) without exception**:

---

### 1. Main Ideas & Workflow (الأفكار الرئيسية وسير العمل)
- Explain the core ideas with concrete real-world scenario examples.
- Provide a clear workflow explaining step-by-step with architecture/flow diagrams (`mermaid`).
- **Required Example**: Concrete practical example showing input/trigger -> process -> output in a real-world scenario.

---

### 2. Detailed Code Breakdown (تحليل الكود بالتفصيل)
- Divide the code into logical chunks/blocks.
- Explain each code chunk in depth.
- Explain **WHY** and **WHEN** to use each code block.
- **Required Example**: Concrete code snippet showing how to use each block and its exact expected output.
- Ensure **100%** of the code is fully covered.

---

### 3. Programming Concepts Breakdown (تحليل المفاهيم البرمجية)
- Extract the core programming concepts used in the code.
- Answer these 3 questions for each concept:
  - **WHAT**: What is this concept?
  - **WHY**: Why do we use it?
  - **WHEN**: When should you use it vs alternatives?
- **Required Example**: A standalone runnable code example demonstrating the concept in action.

---

### 4. Important Topics & Domain Concepts (مفاهيم المجال والذكاء الاصطناعي)
- Extract the key AI / domain concepts relevant to the implementation.
- Answer these 3 questions for each topic:
  - **WHAT**: What is it?
  - **WHY**: Why is it important?
  - **WHEN**: When is it applied?
- **Required Example**: Practical AI/domain calculation, prompt, or latency comparison example.

---

### 5. Topic Summary (ملخص شامل للدرس)
- Summarize everything that has been learned in this step.
- **Required Example**: A consolidated cheatsheet or complete end-to-end integration code example tying all pieces together.

---

### 6. Key Takeaways (أهم النقاط المستفادة)
- Provide clear, memorable key takeaways for the topics covered in this lesson/step.
- **Required Example**: Concrete "Do vs. Don't" practical rules with code mini-examples.

---

> **Strict Rule**: Always provide detailed code and practical examples in EVERY step (1 to 6) without any exception, answered in Arabic language with premium formatting.
